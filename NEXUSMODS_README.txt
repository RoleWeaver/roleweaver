ROLE WEAVER v1.2.1

AI-assisted persistent character and campaign continuity for Neverwinter Nights: Enhanced Edition.

Role Weaver v1.2.1 uses automatic local world/log detection. It does not ship with a named persistent-world server list. New installs show only Auto Detect. Use Rescan Logs to discover worlds from local NWN logs, or Browse... to choose a log file directly.

For setup, see README.md, FIRST_RUN.md, AI_PROVIDER_SETUP.md, and AUTOMATIC_LOG_DETECTION.md.
