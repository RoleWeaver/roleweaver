ROLE WEAVER v1.2.0-alpha6.1 - TEST RELEASE
============================================

TESTERS WANTED
Players and Dungeon Masters are invited to test Role Weaver and report bugs,
confusing behavior, memory mistakes, and suggestions.
Questions and feedback: roleweaverinfo@gmail.com

Role Weaver is an AI-assisted persistent character and campaign-continuity tool
for Neverwinter Nights: Enhanced Edition.

INSTALLATION
1. Extract the ENTIRE ZIP to a normal folder. Do not run from inside the ZIP.
2. Run RoleWeaver.exe.
3. Choose Google Gemini, OpenAI, or LM Studio.
4. Gemini/OpenAI users must create their own API key and paste it into Role Weaver.
5. Press Test AI Connection.
6. Create/select a character profile, choose the server profile, confirm the NWN
   client-log path, then press Start.

GEMINI KEY
- Go to https://aistudio.google.com/
- Sign in, open API Keys, and choose Create API key if needed.
- Copy the key.
- In Role Weaver select Google Gemini, paste the key, and Test AI Connection.

OPENAI KEY
- Go to https://platform.openai.com/
- Create a secret API key in the API Platform.
- Configure API billing/credits if required. ChatGPT subscriptions are separate
  from API billing.
- In Role Weaver select OpenAI, paste the key, choose an available model, and
  Test AI Connection.

SECURITY
Never share your API key with Role Weaver, Nexus Mods, GitHub, Discord, or anyone
else. If exposed, revoke it and create a new one.

INTERNET USE
Role Weaver only needs internet access when you select an online AI provider such
as Gemini or OpenAI. Relevant RP context is sent to the provider you select so it
can generate responses. LM Studio can be used with a local model instead.
