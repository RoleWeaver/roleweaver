ROLE WEAVER — START HERE
========================

Role Weaver is for BOTH players roleplaying their own NWN characters and
Dungeon Masters portraying NPCs.

AFTER INSTALLATION, DO THIS FIRST
---------------------------------

1. SET UP THE AI
   Get a Google Gemini/OpenAI API key OR set up LM Studio.
   Read: AI_PROVIDER_SETUP.md
   Use Role Weaver's Test AI Connection button.

2. CREATE YOUR CHARACTER DESCRIPTION
   Players: start from character_Kaelen_Marr_Player_Character.txt
   DMs: start from character_Captain_Veyra_DM_NPC.txt
   Read: CHARACTER_PROFILE_GUIDE.md

3. CONFIGURE NWN
   Select your server, log file, and character.

4. PRESS START
