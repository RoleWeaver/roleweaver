# Role Weaver Lore

Lore is isolated by server. Put `.txt` lore files inside the folder matching the server selected in Role Weaver.

Examples:

```text
Lore/Arelith/
Lore/TDN/
Lore/RAVENLOFT_POTM/
Lore/CORMYR_DALELANDS/
Lore/STAR_WARS_LOR/
Lore/HAZE_SALTBORNE/
Lore/CUSTOM/
```

Role Weaver will **not** use lore from another server. Files beginning with `always_` are always included when that specific server is selected.

Use the **Lore Editor...** button in Role Weaver to create, paste, load, and save server-specific lore without editing files manually.
