# Lore folders

Role Weaver keeps lore local to each detected world.

Before a world has been detected, generic/default material may live under:

```text
Lore/AUTO/
```

After Role Weaver identifies a world from the player's own NWN client log, it creates and uses a local world-specific folder automatically. No named persistent-world profiles or compatibility claims are bundled with Role Weaver.

Use the Lore Editor in Role Weaver to add material that is appropriate for your own character, campaign, or server.
