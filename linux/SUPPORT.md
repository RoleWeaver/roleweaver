# Support

For bugs and feature requests, use the GitHub issue tracker:

https://github.com/RoleWeaver/roleweaver/issues

Before posting, remove API keys, private conversations, personal file paths, and other sensitive information.

Useful information to include:
- Role Weaver version
- Windows version
- Neverwinter Nights: Enhanced Edition window mode
- selected server profile
- AI provider and model
- relevant Activity-panel output
- whether Keyboard Test succeeds, for input/paste problems
