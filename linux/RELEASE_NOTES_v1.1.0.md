# Role Weaver 1.1.0 — Adaptive Character Memory

Role Weaver 1.1.0 expands the persistent-character system and fixes persistent Guidance.

## Highlights

- Guidance now stays active until you explicitly clear or replace it, including after F8 candidate generation.
- Role Weaver learns recurring vocabulary and speaking style from dialogue your character actually sends in NWN.
- Manual dialogue and edited AI drafts both contribute to the learned voice.
- Explicit character profiles remain authoritative over learned style.
- Per-character structured interaction histories preserve more long-term continuity.
- Important and recent interactions can be brought back into context when a character returns.
- Ongoing story threads preserve promises, investigations, conflicts, debts, goals, and unresolved matters.
- Relationships now show automatic interaction history.
- New Character Memory tab shows the learned voice and story threads, includes **Summarize Now**, and can reset learned voice without deleting relationships or history.
- OOC remains visible in History but is excluded from IC memory learning.

Existing v1.0 memory files are upgraded automatically when loaded; existing notes and relationship records are preserved.
