# Role Weaver v1.2.0-alpha3.1 — Resizable Character Memory

This small UI test release makes the Character Memory tab easier to use.

## Changed

The Character Intelligence summary and Manual Character Knowledge Management areas are now separated by a draggable horizontal sash. Drag the divider up or down to choose how much vertical space each section receives. Both sections also participate in resizing when the main application window is resized.

All Character Intelligence and manual knowledge-management behavior from alpha3 is otherwise unchanged.
