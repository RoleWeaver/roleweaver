# Role Weaver v1.2.0-alpha6 — DM Continuity

Alpha6 focuses on practical continuity for DMs portraying persistent NPCs.

## New
- **NPC Briefing** assembles current state, recent continuity, active threads, commitments, knowledge with provenance, relationships, approved development, and important information the NPC previously shared with players.
- **Campaign Briefing** summarizes campaign DM notes, shared continuity, member NPCs, active threads, commitments, and recent NPC continuity.
- **Shared-with-Player memory** lets the summarizer remember important information an NPC explicitly revealed to a particular player/character. It does not write to or alter Player Knowledge.
- Existing knowledge `source` is surfaced as provenance in NPC briefings.
- DM-only campaign notes remain outside character AI context.

## Included test scenario
The development package included a synthetic **DM Continuity Demo** with example NPC memories exercising relationships, knowledge provenance, commitments, active threads, and prior disclosures to players.

The demo data is fictional test data and can be deleted after testing.
