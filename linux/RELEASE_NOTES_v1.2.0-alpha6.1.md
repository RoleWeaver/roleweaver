# Role Weaver v1.2.0-alpha6.1 — Campaign Manager

> ## Testers wanted
> This is an active public test release. Players and Dungeon Masters are invited to test Role Weaver and report bugs, confusing behavior, memory mistakes, and feature suggestions. Questions and feedback: **roleweaverinfo@gmail.com**.

This release expands the DM continuity tools introduced in alpha6 with a dedicated Campaign Manager while retaining the persistent character, continuity, Adaptive Character, relationship-validation and NPC briefing systems from the preceding alpha releases.

## Campaign Manager
- Campaign name, description and current situation.
- Ordered storyline/story beats with Planned, Active, Completed and Skipped states.
- Objectives and open questions.
- Important locations and DM notes.
- Player/party DM notes kept separate from Player Knowledge.
- Session log with editable summaries.
- Improved NPC roster with access to NPC Briefings.
- Campaign Briefing incorporates current situation, storyline progress, objectives, recent sessions, NPC continuity and DM-only notes.

## DM continuity
- Persistent NPC memory designed to support portrayal by different DMs over time.
- NPC Briefings summarize current state, important knowledge, relationships, commitments, active threads and recent events.
- Important NPC knowledge can retain provenance/source information.
- Role Weaver can remember important information an NPC has already shared with a particular player without writing into that player's own memory.
- DM-only campaign information remains outside character-generation context.

## AI setup
Role Weaver supports Google Gemini, OpenAI and LM Studio. API keys are not included. See `AI_PROVIDER_SETUP.md` for step-by-step Gemini and OpenAI key creation and installation instructions.
