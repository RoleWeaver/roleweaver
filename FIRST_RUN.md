# First Run — Start Here

After Role Weaver is installed, follow this order.

## 1. Configure an AI

Role Weaver cannot generate RP without an LLM. Choose Google Gemini, OpenAI, or LM Studio and follow **AI_PROVIDER_SETUP.md**.

Do not continue until **Test AI Connection** succeeds.

## 2. Create your character description

Players create a profile for their own PC. DMs create a profile for the NPC they are portraying.

Start from one of the included examples:

```text
character_Example_Player.txt
character_Example_NPC.txt
```

Follow **CHARACTER_PROFILE_GUIDE.md**.

## 3. Configure NWN

Leave **World / Server** on **Auto Detect** and confirm the NWN client log path. Role Weaver scans local NWN logs and adds detected worlds to the list automatically.

Use **Rescan Logs** after playing on a new world. If you want to choose a log file directly, use **Browse...**; a detected world is added to the list only after Role Weaver finds it in the selected log.

## 4. Start Role Weaver

Press **Start**. Role Weaver begins following new NWN chat.

## 5. Generate RP

- **F8** — multiple candidate replies.
- **F9** — editable reply placed into NWN.
- **F10** — toggle auto reply.
- **F6** — pause/resume.
- **F11** — clear current conversation context.
- **F12** — stop.

Read and edit generated dialogue before sending it.

**Role Weaver helps you portray the character. You remain the roleplayer.**
